# 🎲 随机画风插件 (anr_plugin_random_artists)

[Auto-NovelAI-Refactor](https://github.com/zhulinyv/Auto-NovelAI-Refactor) 的随机画风插件, 每次生图时随机抽取一定数量的画师, 通过分段 Beta 分布生成随机权重, 组成风格化画风串并生成预览图。相较于 SANP 的随机画风功能, 可调节参数更多且更加方便。

## ✨ 功能特性

- 🎨 **随机画师抽取**: 从画师列表随机抽取指定数量的画师组成画风串
- ⚖️ **分段 Beta 分布权重**: 支持新版权重 (数值权重) 与旧版权重 (括号权重) 两种模式
- 📊 **实时分布图**: 调整权重参数时实时预览数据分布 (直方图 + 核密度估计曲线)
- 📝 **提示词预设**: 正面 / 负面提示词均支持预设角标 (Standard / Light / Heavy 等)
- 🐾 **Furry 模式**: 一键切换 Furry / Anime 生图
- 🎞️ **模型支持**: nai5 / nai4.5 / nai4 / nai3 / furry-3, 支持 vibe 与 wildcards
- 💾 **画师列表管理**: 支持保存 / 还原画师列表文件, 首次启动自动从备份恢复

## 📦 依赖

- matplotlib
- scipy
- numpy
- ujson

## 🚀 使用方法

1. 在 [Auto-NovelAI-Refactor](https://github.com/zhulinyv/Auto-NovelAI-Refactor) 的插件商店中安装本插件
2. 打开「随机画风」面板, 分为 5 个子页签:

### 🖼️ 生成预览

点击 **🚀 开始生成**, 连续生成多张随机画风预览图 (可随时停止)。

### 📝 提示词设置

- **固定正面提示词**: 基础提示词 (可使用 wildcards)
- **正面预设**: Standard / Light / None
- **固定负面提示词**: 基础负面提示词
- **负面预设**: Heavy / Light / Furry Focus / Human Focus / None
- **画风串追加位置**: 最前面 / 最后面 / 自定义 (使用 `__artists__` 占位符指定位置)

### 🎛️ 参数设置

- **模型选择**: nai5 / nai4.5 / nai4 / nai3 / furry-3 全系支持
- **分辨率预设**: 常用尺寸 / 自定义 / 随机
- **采样参数**: 步数、指导系数、重采样系数、种子、采样器、调度器
- **模型增强**: Variety+ / Decrisp / SMEA / DYN / Legacy Prompt Conditioning, 可按概率随机启用
- **vibe 文件**: 支持 `*.naiv4vibebundle` (nai5 不支持)

### 🎨 画师设置

- 画师列表存放于 `./plugins/anr_plugin_random_artists/artists.txt`, 每行一个画师 (或光影质量提示词等)
- 支持 **💾 保存文件** 与 **🔄 还原文件** (从 `artists_backup.txt` 恢复)
- **artist 前缀**: 为画师名添加 `artist:` 前缀

### 🎲 概率设置

- **抽取数量**: 最少 / 最多抽取画师数量
- **年份标签**: 50% 概率附带 year_2022 ~ year_2026 标签
- **随机权重**: 开启后使用分段 Beta 分布随机权重
  - **新版权重**: 可调下界、上界、众数、左右离散程度、负数转化概率、[0,1] 区间增加概率
  - **旧版权重**: 最少 / 最多括号次数, 使用 [] 或 {} 括号

## 💡 权重说明

> 新版权重采用分段 Beta 分布, 可分别控制众数两侧的数据离散程度。上界为最大权重, 下界为最小权重, 众数为最可能的权重; 离散程度越高数据越靠近众数。生成的随机数最多保留 2 位小数, 默认参数可应对大部分场景。

## ⚠️ 注意事项

- 参数设置面板中的参数与主页文生图参数**不通用**
- 复选框类参数 (Variety+ 等) 勾选后按「复选框参数启用概率」生效, 默认 50%
- 数值类参数目前仅可设置为固定值, 下拉列表中的参数可设置为随机
- 当选择不同模型时, 可设置的参数会发生改变
